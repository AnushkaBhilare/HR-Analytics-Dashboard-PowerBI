# HR Analytics Dashboard | Power BI

An end-to-end HR analytics project using Power BI, Excel/CSV, Power Query and DAX to analyze employee attrition, workforce trends and key HR metrics.

## Objectives
- Monitor total employees, active employees and attrition.
- Analyze attrition by department, job role, age group and overtime.
- Track salary, tenure, job satisfaction and workforce demographics.
- Build interactive dashboards using slicers and KPI cards.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Cleaning & Transformation
- Data Visualization

## Dashboard Pages
### 1. HR Overview
KPI cards for Total Employees, Active Employees, Attrition Count, Attrition Rate, Average Salary and Average Tenure, with department and demographic visuals.

### 2. Attrition Analysis
Department-wise, role-wise, age-wise, salary-wise and overtime-based attrition analysis.

### 3. Employee Analysis
Employee demographics, job satisfaction, work-life balance, education and tenure analysis.

## Project Workflow
1. Import HR employee data into Power BI.
2. Clean and transform the data using Power Query.
3. Create calculated measures using DAX.
4. Build relationships and a simple data model.
5. Design interactive dashboards with KPI cards, charts and slicers.
6. Extract insights from employee and attrition patterns.
